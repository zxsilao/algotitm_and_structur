Задание 2. Компоненты связности и двудольность.

Рисунки: sam_2_graf.png, sam_2_color.png

Рёбра по рисунку:
A-B, A-C, B-C, C-D
E-F, F-G
H одна
I-J, J-K, K-L, L-I


Код

from collections import deque

graph = {
    'A': ['B', 'C'], 'B': ['A', 'C'], 'C': ['A', 'B', 'D'], 'D': ['C'],
    'E': ['F'], 'F': ['E', 'G'], 'G': ['F'],
    'H': [],
    'I': ['J', 'L'], 'J': ['I', 'K'], 'K': ['J', 'L'], 'L': ['I', 'K'],
}

def find_components(graph):
    visited = set()
    components = []
    for vertex in graph:
        if vertex in visited:
            continue
        component = []
        stack = [vertex]
        while stack:
            v = stack.pop()
            if v in visited:
                continue
            visited.add(v)
            component.append(v)
            for nb in graph[v]:
                if nb not in visited:
                    stack.append(nb)
        components.append(component)
    return components

def is_bipartite(graph, nodes):
    start = nodes[0]
    color = {start: 0}
    queue = deque([start])
    while queue:
        v = queue.popleft()
        for nb in graph[v]:
            if nb not in color:
                color[nb] = 1 - color[v]
                queue.append(nb)
            elif color[nb] == color[v]:
                return False, None
    return True, color

for comp in find_components(graph):
    ok, color = is_bipartite(graph, comp)
    print(set(comp), ok, color)


Результат

Компоненты:
{A, B, C, D}
{E, F, G}
{H}
{I, J, K, L}

Двудольность:
{A, B, C, D} — нет
{E, F, G} — да: E=0, F=1, G=0
{H} — да: H=0
{I, J, K, L} — да: I=0, K=0, J=1, L=1


Пояснение

DFS из каждой ещё не посещённой вершины собирает одну компоненту.
Их четыре: треугольник с «хвостом», цепочка из трёх, изолированная вершина и цикл из четырёх.

{A, B, C, D} не двудольна: A, B и C образуют треугольник.
Если A — цвет 0, то B и C должны быть цветом 1, но B и C соединены между собой.
Одной вершины D это не спасает: она висит на C.

{E, F, G} — путь длины 2, цвета чередуются.
{H} — одна вершина, двудольна по определению.
{I, J, K, L} — цикл чётной длины, доли {I, K} и {J, L}.
